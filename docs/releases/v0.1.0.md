# Hermes Desktop (Rust) v0.1.0

First tagged build of the native Rust + Slint client, published for all three
platforms. This is an **early vertical slice**, not feature parity: the feature
checklist in `docs/PARITY.md` is the source of truth.

## What works

- Chat against the real backend with streaming replies, thinking blocks and
  tool/terminal rows.
- Sessions sidebar, approvals, model picker, settings shell.
- Single self-contained binary: fonts and icons are compiled in, no web view and
  no JavaScript runtime.

## Known limitations

- **Unsigned builds.** macOS needs right-click → Open on first launch; Windows
  shows a SmartScreen prompt. There is no auto-updater.
- **Linux is Arch-only** (`pacman -U`), by design.
- The in-app browser helper (`hermes-browser`) is a separate GTK/WebKit program
  and is **not** included in these artifacts, so in-app browsing is unavailable
  from a release install.
- The backend is not bundled: the `hermes` CLI must be installed separately.
- Measurements in `docs/PERF.md` were taken on Linux with the software renderer;
  Windows and macOS performance is not measured yet.

## Requirements

- **Linux:** Arch Linux, x86_64.
- **Windows:** Windows 10/11, x86_64, Microsoft Visual C++ runtime.
- **macOS:** 11 (Big Sur) or newer, Apple silicon or Intel.
- The **Hermes Agent backend** (`hermes` CLI) on `PATH`, or an already-running
  gateway passed via `HERMES_DESKTOP_PORT`.
